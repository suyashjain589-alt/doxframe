FAQ

Common questions about DOXFRAME.

Is DOXFRAME free?

Yes. The free plan includes 10 jobs per day. Pro increases the limit to 500 jobs per day.

Are my files uploaded?

Browser-first tools process files locally whenever possible. The account, usage and billing APIs do not receive the file contents. If a future tool needs server-side processing, its data flow will be disclosed before processing.

How long are files stored?

The current browser-first tools do not store your source files on DOXFRAME servers. Job history stores tool names and timestamps, not file contents.

What is the file limit?

The application limit is 50 MB per selected file. Tool-specific browser limits may be lower for very large or complex documents.

Can I use it on mobile?

Yes. The interface is responsive and optimized for touch screens, including Android browsers.

What happens after I reach my limit?

Processing is blocked until the next UTC day, or you can upgrade to Pro for the higher daily limit.

Can I cancel Pro?

Yes. The account area can request cancellation at the end of the current billing cycle when Razorpay billing is configured.

Can conversion formatting change?

Yes. PDF, Word and Excel conversions can vary by source document. Always check the downloaded result before relying on it.
