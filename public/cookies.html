Cookies & Sessions

Last updated: 28 September 2026

Essential session cookie

When you sign in, DOXFRAME uses a Secure, HttpOnly, SameSite session cookie so the browser can remain authenticated. It does not contain your plaintext password.

Turnstile and third-party services

If Cloudflare Turnstile is enabled, Cloudflare may process signals needed to distinguish legitimate users from automated abuse. The widget is used to protect account registration and sign-in, and can also protect feedback submissions when enabled. Account-verification and password-reset emails are delivered through Resend when configured. Payment checkout is handled through Razorpay when Pro billing is enabled. These providers may process information in accordance with their own applicable privacy terms.

Analytics and advertising

The current build does not require an advertising SDK to operate. If analytics or advertising is added later, update this notice and implement any consent requirements that apply to the audiences served.

Browser storage

Browser-first file processing uses in-memory browser APIs and temporary object URLs for the selected files. Source files are not intentionally persisted by the current tool UI.
