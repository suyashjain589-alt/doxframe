# Merged architecture

**Production base:** DOXFRAME V22.1 merged release

**UX layer:** selected SLIKAART V5.2 PDF workspace patterns

**Processing:** browser-first for supported tools

**Backend:** Cloudflare Worker + D1

**Payments:** Razorpay

**Bot protection:** Cloudflare Turnstile

**Canonical public URLs:** hyphenated tool slugs

This keeps one deployable website instead of shipping two separate application stacks.
